## Fee Query Assistant using RAG and Multilingual Tokenization

College students and parents frequently require accurate information about tuition fees, payment deadlines, late-fee rules, instalments, scholarship conditions, and payment procedures. This information is commonly distributed across notices, circulars, and PDF documents, making it time-consuming to locate and difficult to understand for users who prefer a local language. General-purpose chatbots may also produce answers that are not supported by institutional documents.

This project proposes a Retrieval-Augmented Generation (RAG)-based multilingual fee query assistant. The system will process approved, non-confidential college fee documents; split them into searchable sections; retrieve the sections most relevant to a user's question; and generate a concise answer grounded in those sources. The interface will initially support English and one selected local language. Each answer will display the relevant source reference, and the assistant will clearly state when the supplied documents do not contain sufficient information.

The proposed prototype is feasible using document text extraction, multilingual embeddings, a vector database, a language model, and a simple web interface. It will be evaluated with a set of representative fee questions using answer correctness, retrieval relevance, citation coverage, language correctness, and response time. The expected outcome is a transparent and accessible tool that helps students and parents find official fee information while reducing routine administrative queries.

**Keywords:** Retrieval-Augmented Generation, multilingual question answering, fee information, document retrieval, student support.
